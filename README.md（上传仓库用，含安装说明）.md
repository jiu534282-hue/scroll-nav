# Scroll Nav（酒馆竖条导航）

SillyTavern（酒馆）扩展：一条竖状浮动按钮，从上到下三个可按区域：

- **上段 ⇈** 回到聊天最上面（第一条消息）
- **中段 ↑** 跳到上一条消息（自动定位当前视口顶部那条的前一条）
- **下段 ⇊** 回到聊天最下面（最新消息）

整条按钮可按住拖动到任意位置，位置自动记忆（localStorage）。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.js` | 插件本体（全部逻辑都在这一个文件，无外部依赖） |
| `manifest.json` | 扩展清单 |

## 安装（在酒馆 App / 网页内）

1. 打开酒馆的 **扩展** 面板
2. 点 **安装扩展**，粘贴本仓库地址：`https://github.com/<你的用户名>/scroll-nav`
3. 如有分支选项选 `main`
4. 安装完成后刷新/重启酒馆
5. 在扩展面板确认 "Scroll Nav 竖条导航" 已启用

## 手动安装

把 `index.js`、`manifest.json` 两个文件放进酒馆目录：

```
public/scripts/extensions/scroll-nav/
```

然后刷新页面即可。

## 使用

- 上段 ⇈：回到最上面
- 中段 ↑：上一条消息
- 下段 ⇊：回到最下面
- 按住整条按钮可拖动，位置会被记住

## 兼容性

纯 DOM 实现，不依赖酒馆内部 API；桌面版、手机版、任意版本通用。
